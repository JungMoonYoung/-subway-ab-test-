# 지하철 이용행동 A/B Test

> **통제 불가능한 변수 속에서 실험을 설계하고, 통계적으로 검증할 수 있습니다.**

100,000명 × 5 Trial = 500,000 rows의 반복측정 시뮬레이션 데이터에, GEE(AR1) 모델과 FDR 다중검정 보정을 적용하여 혼잡도 피드백 UI가 경로 선택 행동에 미치는 진짜 영향을 분리한 프로젝트입니다.

## 문제 정의 & 해결 방향

### 문제 정의

같은 목적지라도 이용자마다 서로 다른 경로를 선택합니다. 누군가는 빠른 경로를, 누군가는 덜 붐비는 경로를 선호합니다.

### 해결 방향

**현 상황**: 실제 100만 명 대상 현장 실험은 불가능합니다.

1. 현실의 불확실성을 반영한 시뮬레이션을 설계
2. 반복 측정 편향을 GEE 모델로 통제 → **UI 변경만으로 경로 선택 행동이 얼마나 달라지는지를 정량 검증**

## 실험 설계 — 현실의 불확실성을 반영한 시뮬레이션

실제 환경에서 통제 불가능한 요소들을 시뮬레이션에 의도적으로 반영했습니다.

| 현실의 불확실성 | 시뮬레이션 반영 방법 |
|---|---|
| 사람마다 성향이 다름 | 효율지향 / 중립 / 편안함지향 3유형 생성 |
| 혼잡도가 계속 변함 | 이전 선택 결과가 다음 혼잡도에 자동 반영 (동적 피드백) |
| 경험이 쌓이면 행동이 바뀜 | Trial별 학습 효과 (previous_choice 변수 반영) |
| 같은 사람도 매번 다르게 선택 | Bernoulli 분포 기반 확률적 선택 + 로지스틱 회귀 계수 튜닝 |

**데이터 규모**:

- 100,000명 사용자 × 5 Trial 반복 측정
- 총 500,000 rows
- A그룹(빠름 중심 UI) / B그룹(편안함 중심 UI)
- Fast(빠른 경로) / Relax(여유 경로)

## 핵심 결과

### 영향 요인 순위 (GEE 회귀 결과)

| 순위 | 요인 | OR (승산비) | 해석 |
|---|---|---|---|
| 1 | 시간 압박 | 2.55 | 빠른 경로 선택 확률 155% 증가 |
| 2 | 효율지향 성향 | 1.81 | 개인 성향에 따른 빠름 UI 선택 확률 81% 증가 |
| 3 | UI (A그룹) | 1.39 | 보이는 시각적 효과로 39% |
| 4 | 시간 차이 | 1.14 | 시간적 요소는 14%의 차이만을 나타냄 |
| 5 | Trial 증가 | 0.67 | 반복 경험으로 선택 감소 (학습 효과) |
| 6 | 혼잡도 차이 | 0.99 | 미약하나 유의 (p<0.001) |

> **핵심 발견**: 사용자 선택 행동은 UI보다 **상황(시간 압박)·성향(효율지향)** 변수의 영향을 더 크게 받는다.

## 비즈니스 활용 시나리오

### 1. 러시아워 혼잡도 분산 전략

- 러시아워 시간대에 **여유 경로 UI를 노출**하면 혼잡 노선의 이용객 분산 가능
- 2호선 강남~잠실과 같은 혼잡 노선에서, 여유 경로를 추천하고 **"쾌적", "앉아서 이용 가능"** 이라는 문구를 UI에 적용하면 이용객을 분산하여 혼잡도 개선 가능

### 2. 개인화 경로 추천 가능성

- 시간 압박을 조합하면 선택 확률을 **85~94% 범위로 예측 가능**
  - 사용자 프로필 기반 맞춤형 추천 기능으로 사용
- 사용자 프로필 기반 맞춤형 추천
  - 출퇴근 시간 + 효율지향 사용자에게는 소요시간 차이를 강조
  - 여유 시간 + 편안함지향 사용자에게는 혼잡도·쾌적성을 강조

→ 동일 노선에서도 사용자별로 다른 최적 경로 제안 가능

### 3. 동적 피드백의 학습 효과

- 혼잡도 지수를 UI로 지속 제공하면 사용자가 스스로 여유로운 경로를 선택하는 것을 발견
- 별도 규제나 요금 정책 없이 **UI만으로 행동 변화 유도 가능**
- 기존 혼잡 분산 정책과 달리, UI 변경은 추가 비용 없이 **3일차부터 분산 행동 안정화**

## 문제 해결 경험

### 1. 정적 환경의 한계를 극복한 동적 A/B 테스트 시뮬레이션

- **문제**: 초기 시뮬레이션에서 Fast 선택률 **98% 쏠림** → A/B Test 자체가 무의미. 계수 조정, 혼잡도 차이 모두 실패
- **해결**: "사용자 선택 → 혼잡도 변화 → 다음 선택에 영향"이라는 **동적 피드백 루프**를 설계하여 현실적 선택 분포(**71.18%**) 확보
- **배운 점**: 정적 테스트의 경우에는 현실을 반영하지 못한다. 현실을 제대로 반영하는 테스트를 위해서는 **동적으로 관계를 갖는 테스트**를 구성해야 한다.

### 2. 동일 사용자의 반복 선택으로 독립성 가정 위배

- **문제**: 사용자의 선택이 독립성을 위배하며, 시간에 따른 선택 간의 상관관계를 고려하지 않고 진행
- **해결**: **GEE 모델**을 적용하여 반복 측정 효과를 통제하고, **AR(1)** 을 통해서 시간순 선택 간 상관관계를 반영
- **결과**: 개별 사용자의 학습 효과를 고려한 정확한 통계 검정 수행
- **배운 점**: 결론이 다가 아닌 **데이터 구조에 맞는 모델을 제대로 사용**해야 계획했던 분석이 제대로 작동한다는 것을 배웠다.

```bash

# 2. 가상환경 및 의존성
```
